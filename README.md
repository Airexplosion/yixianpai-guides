# 流派攻略订阅

在弈仙牌 Steam 版内订阅人工攻略，跟随境界、轮次与持牌条件查看目标阵容、额外留牌、换牌预算和作者说明。

## 玩家

在 MOD 管理器安装并启用「流派攻略订阅」，通过左侧「攻略订阅」按钮或 **Ctrl+Alt+G** 打开。

1. 在「发现攻略」按攻略名、作者游戏名字、角色或副职搜索。
2. 打开详情，翻阅阶段，点「订阅到本地」。
3. 点「选择攻略」，下一局自动跟随。中途首次选择也支持，但不会假设此前没有消耗换牌次数。
4. 在备战提示窗查看本局建议，目标牌和额外保留牌带文字标记。
5. 详情页点击「原生查看」，在大厅打开游戏自己的秘籍详情面板，使用原生卡图、角色、副职和仙命样式。
6. 不登录也能在[攻略浏览页](https://auth.kaigua.vip/guides)搜索、阅读已发布攻略。复制详情里的 `YXG:...@版本` 订阅码，回到游戏的「我的订阅」粘贴并点击「导入订阅码」，保存该版本到本地。

「我的订阅」可离线打开。详情里的「检查更新」只下载预览，点「保存此版本」才替换缓存；当前对局仍使用已经锁定的版本。取消订阅也不会打断进行中的对局。

## 作者

[作者工作台](https://auth.kaigua.vip/guides)

先完成现有的群认证。使用 ModLoader 0.1.7 或更新版本，打开「授权」页，复制「攻略登录码」并粘贴到工作台登录，无需私聊机器人。登录码 5 分钟有效且只能用一次；授权页可见时到期自动换新，也可在 30 秒冷却后手动换码。

作者身份与已认证的游戏 UID、QQ 在服务器内部绑定，**公开只显示认证记录中的游戏名字，不展示 UID 或 QQ**。发布版本保留发布时的名字。认证过期、解绑、吊销或封禁后需要重新解决认证状态才能发布。

编辑器支持阶段优先级、境界与轮次范围、持牌条件、八格阵容与替代牌、最低牌级、额外留牌数量和理由。换牌预算区分每轮上限、阶段上限、剩余保底；空白表示不限，0 表示不换。草稿只有作者可见，发布后才出现在游戏订阅列表。

角色、副职和游戏版本使用下拉选择，卡牌使用卡图选择。游戏版本来自 ModLoader 检测上报；角色、副职不限时选「全部」。页面可切换中英文，保存时仍保留游戏原始名称用于匹配。留空的阵容格保留为空。

## 行为与限制

- 只展示建议，不自动换牌、炼化或改动对局状态；没有写到的牌显示「攻略未说明」。
- 同优先级多个阶段同时命中时提示冲突；版本不匹配时暂停自动建议，仍能阅读原文。
- 换牌消耗由原生 `ReplaceArea.set_replaceChance` 的下降量观测；次数返还不撤销已观测支出。中途加载、重连或热重载缺少历史时不计算受该历史约束的剩余预算。
- 本地缓存最多 24 份，总订阅内容最多 150KB。当前对局固定的攻略也会落盘，热重载不会切到新发布的版本。
- 网络请求通过 UnityWebRequest 主线程轮询，15 秒超时；失败不覆盖缓存，停用时取消请求并移除自建 UI。
- 作者网页支持卡图选牌：按卡名/效果、门派/副职、境界、等级筛选。阵容、替代牌、持牌条件和留牌均可点选。MOD 安装包不包含卡图、游戏 DLL 或反编译代码。

## 验证状态

0.1.8 包含原生秘籍详情、按手牌数量判断的「如果/否则」阶段、网页订阅码导入和随游戏语言切换的提示。作者网页支持分支预览、八张牌横排、中英文界面与匿名浏览。修复本地订阅空间不足时仍显示导入成功的问题，失败会保留原有订阅。

已通过纯规则测试、Release 编译、ILRuntime 检查与控制字符扫描。作者页面通过浏览器登录、保存、发布、空格阵容、手机布局检查。

**尚未启动游戏验证本 MOD。** UnityWebRequest 的热更运行、按钮位置、牌面标记和换牌计数钩子需要首次实机确认。

## 源码与构建

主开发副本位于加载器仓库 `mods/com.yx.guides`；服务端与作者网页位于其 `apps/auth-server/src/guides`，领码入口位于管理器的「授权」页。

加载器仓库中运行：

```powershell
dotnet build mods/com.yx.guides -c Release
dotnet test mods/com.yx.guides/tests
tools/yx-patch/bin/Release/net8.0/yx-patch.exe check mods/com.yx.guides/plugins/Guides.dll
tools/yx-patch/bin/Release/net8.0/yx-patch.exe pack mods/com.yx.guides
```

独立仓库构建需提供 `YxSdkDir`（Core 与绑定层 SDK DLL）及 `YxRefs`（本机游戏/Unity 引用目录，尾部带目录分隔符）。`UnityEngine.UnityWebRequestModule.dll` 可置于引用目录或其 `dummy` 子目录。不要将这些引用文件提交或打入 MOD 包。

```powershell
dotnet build Guides.csproj -c Release -p:YxSdkDir=C:/path/to/sdk-bin/ -p:YxRefs=C:/path/to/refs/
```
